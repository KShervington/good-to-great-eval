## 1. The great version in one paragraph

Great Corvane is the company every independent chef in its metros knows will get a dead dish machine running before Friday service. It keeps that promise more than 97% of the time, and it does so because its routes are dense, not because its technicians are heroic. It operates in few metros but owns them block by block. Every new account lands inside an existing route, so each placement both shortens drive times and raises contribution per technician. It has several low-cost machine sources (chain remodels, OEM trade-ins, closures) instead of one lucky one, a refurb standard nobody else matches, and sanitizing-temperature logs that make health inspections a non-event. It does not service hotel conveyor lines, does not chase new metros before old ones are dense, and does not need Dev to close the deals.

## 2. The Hedgehog Concept

**Sentence:** *Corvane keeps independent restaurants' dish rooms running faster than anyone else, and it grows by packing more machines onto each technician's route in the metros it already serves.*

**Denominator:** **contribution after field labor, per technician route.** The working proxy is **machines per field technician**: 351 / 17 = **20.6** today.

**Breakeven sensitivity** `[ASSUMPTION]`. This is the number of machines each technician must carry just to cover their own cost, at 63% gross margin:

| Loaded technician cost | At $274/mo | At $289/mo |
|---|---|---|
| $60k | ~29 | ~27 |
| $75k | ~36 | ~33 |
| $90k | ~43 | ~40 |

Today's 20.6 is below breakeven in every row.

**Tests:**

**Confirmation tests (status: working hypothesis):**
1. The home metro reaches breakeven machines per technician within 12 months.
2. 4-hour compliance rises as density rises, both across zones and over time.
3. At least one successor machine source delivers units at ≤$1,800 landed.

## 3. The flywheel

```
   ┌──────────────────────────────────────────────┐
   ▼                                              │
1. 4-hour promise kept (slack + short drives)     │
   │                                              │
2. Chef word-of-mouth · 4.8★ · "fast"             │
   │                                              │
3. New accounts signed INSIDE existing zones      │
   │                                              │
4. Low-cost refurbished machine placed  ◄── WEAKEST LINK (Harrow's ends)
   │                                              │
5. More machines per technician route  (DENOMINATOR)
   │                                              │
6. Contribution per technician rises ────────────┘
   → funds next machines + protects response slack
```

**Current push (the next two turns):**
1. Secure link 4. Lock up the remaining Harrow's/Delmar supply and open two successor sources.
2. Prove link 5→6. Restate the economics with field labor included, then run sales only inside existing zones at $289.

**Doom-loop check:**
- Three of the four agenda items pull outward: a third metro, a hotel service line, and more shop capacity. The east is seven months old and underperforming, yet a third metro is already on the table. That is a new direction before the current one has been turned.
- Larchmont is a classic jump-start: a big contract that delivers instant scale in a different business.
- **Not a doom loop yet, but the offsite is where one would start.**

2. Signing service-only contracts on machines Corvane doesn't own, including Larchmont.
3. Reporting "gross margin" without field labor, to the board or internally. Report contribution per technician instead.
4. Selling accounts outside existing route zones. Every new account should be within a set drive radius of current machines `[ASSUMPTION: e.g., 15 minutes]`.
5. Dev personally closing most large accounts.
6. Buying auction machines at more than ~$3,000 without an account waiting for them.
7. Treating technician slack as waste to fill. Some idle time is the 4-hour promise.
8. Approving shop capacity before machine supply is secured.
