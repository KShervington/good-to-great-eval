## 1. The great version in one paragraph

Great Corvane is the dish machine nobody thinks about, in the restaurants it serves. Chefs in two dense metros pick it because "fast" is a fact: 4-hour response met 95%+ of the time, everywhere it operates. Its economics are driven by density. Every new account lands on an existing route, so each technician serves more machines, response gets faster, and the margin funds machine sourcing that no longer depends on one liquidator's single client. It says no to good revenue that would spend the response buffer: hotel conveyor contracts, scattered accounts, and new metros opened before the last one proved itself. It opens a new metro only when the previous one clears a written density and response gate. Sales no longer depend on Dev's personal network, so the business can outlast him.
