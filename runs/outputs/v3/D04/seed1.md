# Linewright: the great version

**Verdict: good, not yet great. The core is eroding quietly while the founder considers a new product.**

- **Hedgehog:** Linewright makes every professional subtitle file pass the client's delivery spec the first time. The studio sets the rules once, every freelancer's editor enforces them, and the business earns from seats that renew.
- **Most urgent brutal fact:** Renewals fell four quarters in a row (64% → 52%), below your 58% model. Lantern's free auto-align is the reason 69% of buyers chose you, and it ships stable this winter.
- **Weakest flywheel link:** Profit isn't turning into spec-checker progress. Your hours go to licensing tickets and bug-fix releases.
- **Stop:** Linewright Lite; the Linux port; competing on auto-align.
- **Numbers that would change this:** the renewal rate split into studios vs. individuals, and where your 39 studios came from.
- **Confidence:** moderate. The facts are solid. The Hedgehog rests on studio calls and one survey.

Greatness potential: 22/100

## 1. The great version in one paragraph

A great Linewright is the reference tool for spec-compliant subtitles. A studio loads a broadcaster's or streamer's delivery rules once. Every freelancer's file then passes QC on the first try, and the studio can prove it with a per-file report. Studio seats are most of the revenue and almost never churn. Freelancers use Linewright because the studios that pay them run on it, not because it aligns audio (every tool does that by now). It runs on a small, calm team: the founder works on the spec engine and studio relationships rather than on install tickets, and a second person can ship a release. It stays narrow. It is not a creator app, not a Linux project and not a workflow platform. It wins because it is the best at the one thing that costs studios money when it goes wrong.
