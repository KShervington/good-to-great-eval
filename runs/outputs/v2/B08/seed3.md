# Good to Great: Meridian Radio Corporation (as of late summer, Year 0)

## Verdict

**Meridian is already great on its record, so this run uses stewardship mode. It is also showing early signs of decline.**

- **Hedgehog:** Meridian makes the TV set that America's dealers and repairmen trust most, and it earns more per dealer than anyone.
- **Weakest flywheel link:** turning profit into next-generation reliability. Cash is going to hand-wiring, inspection labour, a color-capacity race and pay TV. It is not going to solid-state designs.
- **Temptations to refuse:** (1) a debt-funded race to out-build Rival R in color; (2) defending hand-wiring as the brand when the brand is really reliability; (3) open-ended pay-TV spending.
- **Most urgent brutal fact:** the capacity being built now locks in a production method the industry is leaving. Leadership publicly dismisses both integrated circuits and imports.
- **Missing numbers that would change this:** field-failure rate and cost per set for hand-wired, printed-circuit and imported sets; import volumes and prices; color share; debt and capex.
- **Confidence:** medium-low. It rests on a qualitative dossier with no cost, reliability or import data.

Greatness potential: 30/100

## 1. The great version in one paragraph

Great Meridian is the **reliability benchmark** in home electronics. It does not compete on hand-wiring. It competes on sets that work, keep working, and can be fixed in minutes. It keeps the trust of repairmen and dealers that it earned with hand-built sets. It earns that trust again with whatever circuit technology proves most reliable and serviceable, which is likely solid-state modular chassis that a repairman can swap rather than solder. It is the first to prove the new method is better instead of the last to admit it.

It adds color capacity only as fast as dealer sell-through justifies, and it stays close to debt-free. It measures low-cost imports instead of dismissing them, and it beats them on reliability per dollar. It has a leadership bench beyond the founder's lieutenants. The pay-TV bet is either licensed, staged behind regulatory milestones, or ended.

## 5. Stop-doing list (stewardship mode: real temptations only)

1. **Stop racing Rival R for color unit share with borrowed money.** Add capacity only against proven dealer sell-through.
2. **Stop treating hand-wiring as the brand.** The brand is reliability. Keep hand-wiring only where data shows it still wins on reliability per dollar.
3. **Stop open-ended pay-TV spending.** Set a regulatory deadline and a spending cap.
4. **Stop dismissing imports without measuring them.** Today's "cheap and small" set is an entry point, not a ceiling.
5. **Refuse the counter-temptation:** do not answer imports with stripped-down, cheaper Meridian sets that dilute the reliability promise.

**The three tests of great:**

**Ruling:** Meridian has held all three tests for years, so it qualifies as already great. Stewardship mode applies, with Gate 10 at the center.
